# D 盘影视资源自动分类整理脚本

自动扫描 D 盘视频文件，按 **电影 / 电视剧 / 动漫 / 纪录片** 分类，并按分辨率（4K / 1080P / 720P）整理到对应目录。

## 功能特性

- 🎬 **自动分类**：根据文件名规则识别电影、电视剧、动漫、纪录片
- 📺 **分辨率识别**：自动识别 4K / 1080P / 720P / 480P
- 📁 **目录整理**：按 `分类 / 分辨率 / 文件名` 的层级结构组织
- 👀 **Dry-run 预览**：默认只预览不移动，确认无误后再执行
- 📝 **日志输出**：支持输出到文件，方便回溯
- 🚫 **重名处理**：自动加 `_1`、`_2` 后缀避免覆盖

## 目录结构

执行后目标目录结构如下：

```
D:\Media\
├── 电影\
│   ├── 4K\
│   ├── 1080P\
│   └── 720P\
├── 电视剧\
│   ├── 4K\
│   ├── 1080P\
│   └── 720P\
├── 动漫\
│   └── ...
└── 纪录片\
    └── ...
```

## 快速开始

```bash
# 1. 预览模式（推荐先跑一遍，不实际移动文件）
python media_organizer.py

# 2. 确认无误后，实际执行移动
python media_organizer.py --apply

# 3. 指定扫描目录和输出目录
python media_organizer.py --src D:\Videos --dest D:\Media --apply

# 4. 只处理指定格式
python media_organizer.py --extensions mp4,mkv --apply

# 5. 输出日志到文件
python media_organizer.py --apply --log organize.log
```

## 分类规则

| 类型 | 识别规则 |
|------|----------|
| **动漫** | 文件名包含 anime / 动画 / 动漫 / 番剧 / 日漫 等关键词 |
| **纪录片** | 文件名包含 documentary / 纪录片 / BBC / 国家地理 等关键词 |
| **电视剧** | 匹配 SxxExx、Season 1、第x集、EP01 等剧集模式 |
| **电影** | 以上都不命中时，默认为电影 |

## 参数说明

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `--src` | `D:\` | 扫描根目录 |
| `--dest` | `D:\Media` | 分类输出目录 |
| `--apply` | False | 实际执行移动（不加则为预览模式） |
| `--extensions` | 全部常见视频格式 | 逗号分隔的视频扩展名 |
| `--log` | 仅控制台 | 日志文件路径 |

## 注意事项

1. **建议先跑预览模式**，确认分类结果符合预期后再加 `--apply`
2. 脚本会跳过目标输出目录自身，避免重复处理
3. 依赖仅 Python 标准库，无需安装第三方包
4. 移动操作不可撤销，请提前备份重要文件
